# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Please read it there; it is not reproduced here so that it cannot drift out
of date.

## In short

Be decent. Assume the other person is trying to make the tool better. Criticise the artifact, not the
person.

## Reporting

Report unacceptable behaviour privately to the maintainer at <stop-cran@list.ru>. Reports are handled
confidentially. The maintainer will respond as promptly as circumstances allow and may remove
comments, close threads, or block accounts.

## A note specific to this project

Technical disagreement is welcome here and is the point of the whole apparatus in
[CONTRIBUTING.md](CONTRIBUTING.md). Saying "the specification is wrong" is a normal, expected,
valued contribution — that is what the specification-ambiguity route exists for.

Two things that are *not* welcome, because they cost other people real time:

- Presenting reasoning as observation. Mark untested claims as untested.
- Filing volume without triage — duplicates, or reports without the version and repro.

Both apply equally to humans and to agents acting on their behalf. If you run an agent against this
repository, you are responsible for what it files.
